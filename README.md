## 선택지

- `자동알림`, `자동삭제`, `나만보기`, `사진첨부`, `/누락소식설정`의 `허용`, `/점검알림설정`의 `허용`, `/치지직알림설정`의 `허용` 옵션은 `허용` 또는 `비허용` 중에서 고릅니다.
- `/서버설정`, `/소식채널설정`, `/소식채널해제`, `/유저설정`의 `언어` 옵션은 `한국어`, `English`, `日本語`를 지원합니다.
- `/서버설정`의 `언어`는 자동 발송 채널 언어가 아니라 서버 관리자 명령어에서 게시물을 고르고 볼 때 쓰는 기본 언어입니다.
- `/서버설정`의 `뉴스소스`는 `둘 다`, `Steam`, `X(트위터)` 중에서 고릅니다. 기본값은 `둘 다`입니다.
- `/서버설정`, `/유저설정`의 `알림배너` 옵션은 `img` 폴더의 배너 이미지를 이미지 이름으로 선택합니다. 현재 `단테 배너`, `림피 배너`, `사용 안 함`을 사용할 수 있습니다.
- X 게시물 동기화와 자동 발송은 `.env`의 `X_AUTH_TOKEN`, `X_CT0` 쿠키 값이 필요합니다. X GraphQL 404가 나면 `X_QID_USER_BY_SCREEN_NAME`, `X_QID_USER_TWEETS_AND_REPLIES`를 새 값으로 덮어씁니다.

## 언어별 소식 채널

`/소식채널설정`으로 자동 소식을 받을 채널과 언어를 따로 등록합니다.

예시:

- `/소식채널설정 언어: 한국어 채널: #ko-news`
- `/소식채널설정 언어: English 채널: #en-news`
- `/소식채널설정 언어: 日本語 채널: #jp-news`

새 소식 자동 발송은 각 채널 설정 언어에 맞는 게시물을 보냅니다. `/소식보내기`에서 채널을 비우면 선택한 소식의 같은 Steam 게시물을 언어별 채널에 맞춰 찾아 보냅니다. 예를 들어 한국어 게시물을 선택해도 English 채널에는 같은 게시물의 English 버전을 보냅니다.

같은 서버에서 같은 채널은 한 언어로만 등록됩니다. 이미 등록된 채널을 다른 언어로 다시 설정하면 중복 추가가 아니라 기존 채널의 언어가 새 언어로 바뀝니다.

## 누락 소식 자동 재시도

`/누락소식설정`을 `허용`으로 설정하면, 림피가 권한 오류나 일시적인 Discord 오류 때문에 새 소식을 자동 발송하지 못했을 때 해당 소식을 본 것으로 처리하지 않습니다. 이후 채널 권한을 고치거나 오류가 해소되면 다음 뉴스 확인 때 다시 발송을 시도합니다.

기본값은 `비허용`입니다. 이 경우 실패한 소식도 기존처럼 읽음 처리되어 다음 자동 확인에서 다시 보내지 않습니다.
