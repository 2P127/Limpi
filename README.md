## 명령어

| 명령어 | 설명 | 사용 범위 | 권한 |
| --- | --- | --- | --- |
| `/봇서버설정` | 서버 알림 채널, 역할 핑, 자동 알림, 언어, 이미지 전송 방식, 자동 삭제 여부와 삭제 일수를 설정합니다. | 서버 | 서버 관리 |
| `/봇유저설정` | 앱으로 사용할 때의 개인 뉴스 언어를 설정합니다. | 서버, DM | 없음 |
| `/역할핑해제` | 새 소식 알림에 붙는 역할 핑을 제거합니다. | 서버 | 서버 관리 |
| `/서버설정상태` | 현재 봇 서버 설정과 뉴스 소스 상태를 확인합니다. | 서버 | 서버 관리 |
| `/서버동기화` | Steam 뉴스 소스와 디스코드 서버 설정을 즉시 동기화합니다. | 서버 | 서버 관리 |
| `/최근소식보기` | 설정된 언어의 가장 최근 림버스 컴퍼니 소식을 가져와 보여줍니다. | 서버, DM | 없음 |
| `/소식보내기` | 저장된 소식을 선택해 지정한 채널에 역할 멘션과 함께 보냅니다. | 서버 | 서버 관리 |
| `/이전소식보기` | 저장된 이전 소식을 다시 확인합니다. | 서버, DM | 없음 |
| `/프문그림보기` | 등록된 프로젝트문 공식 그림만 랜덤 또는 선택해서 봅니다. | 서버, DM | 없음 |
| `/명령어` | 림피의 명령어 안내를 표시합니다. | 서버, DM | 없음 |

## 명령어 옵션

| 명령어 | 옵션 |
| --- | --- |
| `/봇서버설정` | `채널`, `역할`, `자동알림`, `언어`, `이미지전송`, `자동삭제`, `자동삭제일수` |
| `/봇유저설정` | `언어` |
| `/소식보내기` | `게시물`, `채널`, `역할` |
| `/최근소식보기` | `나만보기` (기본 켜짐) |
| `/이전소식보기` | `게시물`, `나만보기` (기본 켜짐) |
| `/프문그림보기` | `그림`, `나만보기` (기본 켜짐) |

`언어` 옵션은 `한국어`, `English`, `日本語`를 지원합니다. 
(언어에 따라 소식 이미지와 설명의 언어가 변경됩니다.)

`/프문그림보기`는 `data/pm_drawings.json`에 등록된 그림만 보여줍니다.
X/Twitter 자동 수집은 API 키나 별도 수집기가 필요하므로, 우선 공식 그림 URL과 이미지 URL을 JSON에 넣어 관리합니다.
형식 예시는 `data/pm_drawings.example.json`에 있습니다.
