## 명령어

슬래시 명령 이름은 봇 코드(`bot.py`)에 등록된 값과 동일합니다.

| 명령어 | 설명 | 사용 범위 | 권한 |
| --- | --- | --- | --- |
| `/서버설정` | 알림 채널·역할 핑·자동 알림·Steam 뉴스 언어·이미지 전송 방식·조회 메시지 자동 삭제(유예 1~7일)를 설정합니다. | 서버만 | 서버 관리 |
| `/유저설정` | 유저 앱(개인 설치)으로 쓸 때 `/최근소식보기`, `/이전소식보기`에 쓸 언어를 정합니다. | 서버·DM·개인 채널 | 없음 |
| `/서버설정상태` | 위 서버 설정 값과 뉴스 소스 요약을 확인합니다. | 서버만 | 서버 관리 |
| `/역할핑해제` | 새 소식 알림에 붙는 역할 핑을 제거합니다. | 서버만 | 서버 관리 |
| `/서버동기화` | Steam 뉴스를 즉시 가져와 캐시·서버 읽음 상태를 맞춥니다. | 서버만 | 서버 관리 |
| `/최근소식보기` | 설정 언어 기준 가장 최근 소식을 가져와 보여 줍니다(실패 시 캐시 최신 글). | 서버·DM·개인 채널 | 없음 |
| `/소식보내기` | 저장된 소식을 골라 지정 채널에 역할 멘션과 함께 보냅니다. 채널·역할을 비우면 `/서버설정` 값을 씁니다. | 서버만 | 서버 관리 |
| `/이전소식보기` | 캐시에 저장된 과거 소식을 다시 봅니다. 자동완성은 설정 언어로 걸러집니다. | 서버·DM·개인 채널 | 없음 |
| `/명령어` | 봇 안내 임베드를 띄웁니다. | 서버·DM·개인 채널 | 없음 |

## 명령어 옵션

| 명령어 | 옵션 |
| --- | --- |
| `/서버설정` | `채널`, `역할`, `자동알림`, `언어`, `이미지전송`, `자동삭제`, `자동삭제일수` |
| `/유저설정` | `언어` |
| `/소식보내기` | `게시물`, `채널`, `역할` |
| `/최근소식보기` | `나만보기` (기본 켜짐) |
| `/이전소식보기` | `게시물`, `나만보기` (기본 켜짐) |

`/서버설정`과 `/유저설정`의 `언어` 옵션은 `한국어`, `English`, `日本語`를 지원합니다.  
(Steam 뉴스·소식 본문·이미지가 선택한 언어에 맞춰집니다.)
