## 명령어

| 명령어 | 설명 | 사용 범위 | 권한 |
| --- | --- | --- | --- |
| `/서버설정` | 알림 채널, 역할 핑, 자동 알림, Steam 뉴스 언어, 이미지 전송 방식, 조회 메시지 자동 삭제를 설정합니다. | 서버만 | 서버 관리 |
| `/누락소식설정` | 권한 오류나 일시 오류로 자동 발송에 실패한 새 소식을 다음 확인 때 다시 보낼지 설정합니다. | 서버만 | 서버 관리 |
| `/유저설정` | 유저 앱 또는 DM에서 `/최근소식보기`, `/이전소식보기`에 사용할 개인 언어를 설정합니다. | 서버·DM·개인 채널 | 없음 |
| `/서버설정상태` | 현재 서버 설정 값과 뉴스 소스 상태를 확인합니다. | 서버만 | 서버 관리 |
| `/역할핑해제` | 새 소식 알림에 붙는 역할 핑을 제거합니다. | 서버만 | 서버 관리 |
| `/서버동기화` | Steam 뉴스를 즉시 가져오고 현재 서버의 읽음 기준을 동기화합니다. | 서버만 | 서버 관리 |
| `/최근소식보기` | 설정 언어 기준 가장 최근 소식을 가져와 보여 줍니다. | 서버·DM·개인 채널 | 없음 |
| `/소식보내기` | 저장된 소식을 골라 지정 채널에 역할 멘션과 함께 보냅니다. | 서버만 | 서버 관리 |
| `/이전소식보기` | 캐시에 저장된 이전 소식을 다시 봅니다. 자동완성은 설정 언어로 필터링됩니다. | 서버·DM·개인 채널 | 없음 |
| `/명령어` | 봇 안내 임베드를 띄웁니다. | 서버·DM·개인 채널 | 없음 |

## 명령어 옵션

| 명령어 | 옵션 |
| --- | --- |
| `/서버설정` | `채널`, `역할`, `자동알림`, `언어`, `이미지전송`, `자동삭제`, `자동삭제일수` |
| `/누락소식설정` | `허용` |
| `/유저설정` | `언어` |
| `/소식보내기` | `게시물`, `채널`, `역할` |
| `/최근소식보기` | `나만보기`, `사진첨부` |
| `/이전소식보기` | `게시물`, `나만보기`, `사진첨부` |

## 선택지

- `자동알림`, `자동삭제`, `나만보기`, `사진첨부`, `/누락소식설정`의 `허용` 옵션은 `허용` 또는 `비허용` 중에서 고릅니다.
- `/서버설정`과 `/유저설정`의 `언어` 옵션은 `한국어`, `English`, `日本語`를 지원합니다.
- `/서버설정`의 `이미지전송` 옵션은 `첨부파일`, `임베드`를 지원합니다.

## 누락 소식 자동 재시도

`/누락소식설정`을 `허용`으로 설정하면, 림피가 권한 오류나 일시적인 Discord 오류 때문에 새 소식을 자동 발송하지 못했을 때 해당 소식을 본 것으로 처리하지 않습니다. 이후 채널 권한을 고치거나 오류가 해소되면 다음 뉴스 확인 때 다시 발송을 시도합니다.

기본값은 `비허용`입니다. 이 경우 실패한 소식도 기존처럼 읽음 처리되어 다음 자동 확인에서 다시 보내지 않습니다.
